# CaseSolve / Кейсовл ⚖️

Telegram-бот для организации справедливых судебных разбирательств в группах.

## Переменные окружения (Render)

| Переменная   | Описание                                              | Обязательна |
|-------------|-------------------------------------------------------|-------------|
| `TOKEN_BOT` | Токен бота от @BotFather                              | ✅ Да       |
| `RENDER_URL`| URL вашего сервиса на Render (для само-пинга)         | Рекомендуется |
| `DB_PATH`   | Путь к файлу базы данных (по умолчанию `data/casesolve.db`) | Нет |

## Деплой на Render

1. Загрузите проект на GitHub
2. Создайте новый сервис на [Render](https://render.com):
   - Тип: **Web Service** (чтобы не засыпал через `/ping`)  
     _или_ **Background Worker** (платный план, не засыпает)
3. Укажите команды:
   - **Build Command:** `pnpm install && pnpm --filter @workspace/telegram-bot run build`
   - **Start Command:** `node artifacts/telegram-bot/dist/index.js`
4. Добавьте переменные окружения:
   - `TOKEN_BOT` = ваш токен от @BotFather
   - `RENDER_URL` = URL вашего сервиса (например `https://casesolve.onrender.com`)
5. Добавьте диск (Disk) размером 1 ГБ, примонтируйте в `/var/data`, установите `DB_PATH=/var/data/casesolve.db`

## Анти-сон на Render (бесплатный план)

Бот автоматически пингует себя каждые 14 минут через `RENDER_URL/ping`.  
Дополнительно рекомендуется настроить [UptimeRobot](https://uptimerobot.com/) для мониторинга — бесплатно пингует каждые 5 минут.

## Права бота в группе

Бот должен быть **администратором** в:
- Группе, откуда поступают иски (для получения информации об участниках)
- Чате для проведения судов (для управления мутом участников)

Необходимые права:
- ✅ Удалять сообщения
- ✅ Ограничивать участников (мут)
- ✅ Удалять участников (кик после завершения суда)

## Команды бота

### Для участников:
- `! суд @username` — подать иск против участника
- `! суд` (в ответ на сообщение) — подать иск против автора
- `/lawsuit @username` — альтернативная форма

### Для администраторов/владельца:
- `! суд` или `/lawsuit` — создать суд вручную с выбором всех участников

### В личных сообщениях (для владельца):
- `/настройки` или `/settings` — настроить чат для судов
- `/start` — начало работы с ботом
- `/help` — справка

## Как проходит суд

1. **Вызов** — участник пишет `! суд @user`
2. **Создание** — владелец нажимает «Создать суд», указывает свидетелей
3. **Заседание** — истец говорит → его мутят → ответчик говорит → его мутят → повторяется
4. **Решение** — судья нажимает «Принять решение» → все в муте → судья выбирает вердикт
5. **Завершение** — вердикт объявлен, можно удалить участников и историю
